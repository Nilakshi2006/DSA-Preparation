## 🎯 Why I Started with Patterns

Pattern problems are one of the best ways to start learning DSA because they strengthen the basics of programming. By solving these questions, I focused on:

- Understanding nested loops.
- Building logical thinking.
- Improving problem-solving skills.
- Learning how to break a problem into smaller steps.
- Writing clean and structured C++ code.
